트레이 아이콘 (tray-icon.png) 을 이 폴더에 넣어주세요.

권장 규격:
- Windows: 16x16 또는 32x32 PNG
- Mac: 16x16, 18x18, 32x32, 36x36 (template image, @2x 대응)

급한 경우 결 웹앱의 favicon (public/icon.svg) 을 PNG 로 변환해서 사용 가능:
  결 로고 → 32x32 PNG → tray-icon.png

코드 사이닝(연 ~20만원) 안 한 상태에서 NSIS 빌드 시 Windows SmartScreen 경고가 한 번 뜹니다.
설치 안내문에 "추가 정보 → 실행" 가이드 포함하면 베타 6개월간 충분.
