# 결(Gyeol) 제품 소개서

> **한 줄 소개** — 손님 주문부터 단골 관리, 재고·매출, AI 마케팅까지.
> 사장님 한 분이 매장 전부를 폰 하나로 운영하는 **올인원 매장 운영 클라우드(CRM + ERP + POS)**.

**문서 버전** v1.1 · **작성일** 2026-06-24 · **대상** 투자·파트너·팀 온보딩·포트폴리오용 통합 소개

---

## 0. 30초 요약

결(Gyeol)은 식당·카페 사장님이 **QR 주문 → 결제 → 단골 관리 → 매출·재고 분석 → 마케팅**까지 하나의 앱으로 끝내는 매장 운영 플랫폼입니다.

- **POS** — QR 주문, 주방 디스플레이, 키오스크, 토스플레이스 오프라인 매출 자동 연동
- **CRM** — 단골 자동 분류(VIP·신규·이탈위험·휴면), 등급·쿠폰·리뷰·재방문 유도
- **ERP** — 재고·원가·정산·매출장부, 직원 권한 등급·출퇴근·급여
- **AI 비서** — 도면 자동 배치, 영수증 인식, 마케팅 콘텐츠 생성, 리뷰 응대, AI 전화 예약
- **무료로 시작** — 베타 기간 사용료 0원, 채널 1개 무료(Free) / 다채널 Pro(월 ₩10,000)
- **4개 언어** — 한국어·English·Tiếng Việt·中文 (손님·직원 다국적 매장 대응)

벤치마크는 **토스 POS**. 다만 토스가 결제 중심이라면, 결은 **"손님·단골·마케팅·운영을 하나로 묶는 두뇌"**를 지향합니다.

---

## 1. 왜 결인가 — 문제와 해법

### 사장님이 겪는 현실
- POS는 결제만, 단골 관리는 따로, 배달·예약·리뷰는 각각 다른 앱 → **흩어진 데이터**
- 마케팅은 손이 많이 가고, 직원이 바뀌면 노하우가 사라짐
- 재고·원가·세무는 "감"으로 운영 → 새는 돈이 안 보임

### 결의 해법
| 흩어진 도구 | 결의 통합 |
|---|---|
| POS / 키오스크 / 배달앱 | **QR 주문 + 키오스크 + 주방 디스플레이** 한 화면 |
| 단골 스탬프 앱 / 문자 발송 | **자동 단골 분류 + 등급·쿠폰 + 알림톡/SMS** |
| 엑셀 재고·원가 | **재고·원가 ERP(3가지 모드) + 매출장부·정산** |
| 외주 마케팅 / 블로그 대행 | **AI 마케팅 비서(초안→승인→발행) + 리뷰 SNS 공유** |
| 전화 예약 받기 | **AI 전화 예약**(음성으로 자동 응대·예약) |

**핵심 철학** — "사장님이 누르는 버튼을 줄인다." 예: 주문 처리는 다른 POS의 4단계를 **2단계(접수→서빙)**로 단순화. 테이블은 8단계를 대부분 **자동 전이**.

---

## 2. 누가 쓰나 — 4개 역할 × 다국어

결은 하나의 앱에서 **3개 역할**로 동작하며, 직원은 다시 **4개 권한 등급**으로 세분화됩니다.

### 손님 (Customer)
- QR 스캔 → 메뉴 주문 → 결제 → 리뷰 작성
- 내 단골 매장·쿠폰·등급 한눈에
- 리뷰를 **AI가 다듬어** 구글·인스타에 한 번에 공유

### 사장님 (Owner)
- 매장의 모든 기능에 접근하는 관리자
- 대시보드·메뉴·테이블·주문·고객·재고·통계·정산·마케팅·설정 전권

### 직원 (Staff) — 권한 등급 4단계 ⭐신규
높은 등급은 하위 등급 권한을 모두 포함(누적):

| 등급 | 직책 | 기본 권한 |
|---|---|---|
| **1** | 알바생 | 주문 접수·서빙, 테이블 상태 변경, 출퇴근 |
| **2** | 정규직 | + 고객 조회, 예약 관리 |
| **3** | 매니저 | + 재고·통계 |
| **4** | 실장 | + 정산·직원 운영 보조 |

- 사장님이 직원별로 **개별 권한 추가(extraPerms)** 가능 — 예: "정규직이지만 정산만 추가 허용"
- 출근(클록인) 상태에서만 운영 페이지 접근 → 보안·근태 동시 관리
- 시급 설정 → 출퇴근 기록 기반 **급여 계산**

### 다국어 — 4개 언어 내장
한국어 · English · Tiếng Việt · 中文.
외부 라이브러리 없는 자체 i18n으로, 손님·직원이 각자 언어로 사용. 사장님이 받는 푸시 알림도 설정 언어로 발송.

## 3. 기능 전체 지도

### 🧾 POS · 주문 운영
- **QR 테이블 주문** — 손님이 테이블 QR을 찍으면 메뉴·옵션 선택·주문
- **메뉴 옵션 시스템** — 온도(아이스/핫), 양(곱빼기 +1000) 등 옵션 그룹·모디파이어. 옵션 선택분이 단가·재고에 자동 반영
- **주방 디스플레이(KDS)** — 주문이 주방 화면에 실시간 표시
- **키오스크 모드** — 매장 태블릿 셀프 주문
- **빠른 주문(QuickOrder)** — 사장님·직원이 대신 주문 입력
- **테이블 8단계 워크플로우** — 비어있음→예약→세팅→입장→식사중→결제완료→정리중→비어있음 (대부분 자동 전이)
- **테이블 편집기** — 도면 위에 테이블 드래그 배치, 룸·섹션·좌석수·모양 지정
- **결제** — 토스 결제 연동 + 현금 수동 승인, 결제수단별 매출 분리
- **영수증 자동 인쇄** — PC 트레이 브릿지 앱 페어링 → 결제 승인 시 자동 출력(POS API → 브릿지 → 브라우저 순 폴백)

### 👥 CRM · 단골 관리
- **자동 고객 분류** — VIP 레전드 / 유망 신규 / 이탈 위험 / 장기 휴면
- **등급제 + 포인트/스탬프** — 업종별 보상 방식 선택, 등급명·보상 커스터마이즈
- **쿠폰** — 개별·일괄 발급, 금액 쿠폰은 결제 시 자동 차감, 사용 요청 승인 흐름
- **리뷰 시스템** — 별점·추천·키워드 태그·한줄 제목·사진, 사장님 답글
- **리뷰 보상 쿠폰** — 손님이 리뷰 남기면 자동 쿠폰 지급
- **리뷰 SNS 공유** ⭐ — AI가 리뷰를 다듬어 손님이 구글·인스타에 게시(공유 의도 추적·분석)
- **고객 데이터 엑셀(CSV) 내보내기** — 한글 깨짐 없이

### 📦 ERP · 재고 · 정산
- **재고/원가 관리 3가지 모드**
  - `full` — 원재료·레시피 기반 깐깐한 ERP(판매 시 자동 차감)
  - `simple` — 간편 입력
  - `ai` — AI 자동 원가율 추정
- **레시피 연동** — 메뉴 1인분 원재료 정의 → 판매 시 자동 차감 + 원가 계산
- **부족 알림** — 임계값 이하 시 알림
- **매출장부·정산** — 카드/현금/수동 매출 통합, 지출(임대·인건비·재료·공과금·마케팅) 입력 → 순이익
- **통계 대시보드** — 오늘/어제 비교, 시간대별·요일별·메뉴별·등급별·연령대별 분석

### 🤖 AI 비서 (Google Gemini 기반)
- **도면 → 테이블 자동 배치** — 매장 사진/스케치 업로드 → AI가 30초 내 테이블 초안 생성
- **영수증 인식(OCR)** — 종이 영수증을 읽어 매출/지출 자동 입력
- **메뉴판 생성** — 메뉴 데이터로 디자인 메뉴판 제작
- **세무 도우미** — 세금 관련 질의응답
- **사장님 비서(고객지원)** — 운영 질문 AI 응답
- **비즈니스 인사이트** — 매출·고객 데이터 자동 분석·제안
- **마케팅 자율 에이전트** ⭐ — 게시물·리뷰 응대 **초안 자동 생성 → 사장님 승인 → 발행**(자동 발행은 기본 OFF, 감사 로그·하루 발행 한도 등 가드레일)
- **AI 전화 예약** ⭐ — 매장 대표번호로 걸려온 전화를 AI가 음성으로 응대·예약(매장별 인사말·예약 시간 설정)

### 🏪 브랜드 · 공개 사이트
- **가게 공개 브랜드 사이트**(`/site/:storeId`) — 테마·글꼴·태그라인·주소·찾아오시는 길
- **업종별 테마** — 카페·고깃집·베이커리·일반, 색 테마·폰트 프리셋
- **환영 디스플레이** — 듀얼 모니터/대형 화면에 손님용 화면 송출
- **소상공인 지원정보** — 정책·지원사업 안내

### 🔔 알림 · 예약
- **푸시 알림(FCM)** — 새 주문·결제 요청·직원 가입·쿠폰 사용을 폰·태블릿·PC 다중 기기로, 종류별 ON/OFF
- **예약 관리** — 단골 검색·게스트 추가, 예약 확정/방문완료/노쇼/취소, 테이블 자동 연동
- **영업 시간** — 요일별·휴게시간·휴무일·24시간, 영업 외 손님 주문 자동 차단, 긴급 임시 마감 토글

### 🔐 인증 · 멀티테넌시
- **멀티 로그인** — 전화 SMS 인증, 구글, 카카오, 네이버
- **매장 간 데이터 완전 분리** — 손님은 QR 찍은 매장만, 쿠폰은 발급 매장에서만
- **운영 영역(`/biz/*`) 검색엔진 차단** + 손님에게 운영자 입구 비노출

## 4. 업데이트 하이라이트 (최근 변경)

이번 사이클에서 결이 **POS를 넘어 CRM+ERP 통합앱**으로 확장된 핵심 변화:

1. **직원 권한 등급 시스템(StaffLevel 1~4) + 모바일 UX** — 현재 작업 브랜치. 등급별 화면 접근 제어 + 개별 권한 추가
2. **토스플레이스 매출 자동 연동** — 오프라인 토스 POS 결제를 웹훅으로 받아 매출에 자동 기록(서명검증 비차단화로 누락 방지)
3. **마케팅 자율 에이전트("사장님 비서")** — 콘텐츠·응대 초안 생성→승인→발행, 감사 로그·발행 한도 가드레일
4. **리뷰 SNS 공유 + AI 리뷰 포장** — 손님 리뷰를 AI로 다듬어 구글·인스타 공유, 공유 분석
5. **메뉴 옵션 시스템** — 옵션 그룹/모디파이어, 옵션 반영 단가·재고 차감
6. **재고/원가 ERP 3모드(full/simple/ai)** + 레시피 자동 차감
7. **AI 전화 예약** — 음성 채널 자동 응대
8. **가게 공개 브랜드 사이트 + 테마·폰트 시스템**
9. **결 요금제(Free/Pro)** 도입

## 5. 기술 스택

### 프론트엔드
- **React 19** + **TypeScript 5.9** + **Vite 7**
- **Tailwind CSS v4** (CSS 변수 기반 매장별 동적 테마)
- **react-router-dom v7** — 코드 스플리팅(lazy/Suspense)으로 화면별 분할 로딩
- **lucide-react**(아이콘) · **motion**(애니메이션) · **clsx/tailwind-merge**
- **qrcode.react**(QR 생성) · **html5-qrcode**(QR 스캔) · **date-fns**

### 백엔드
- **Node.js 22** + **Express 5** (`server.ts`, tsx/esbuild 번들)
- **firebase-admin** — 서버측 Firestore·인증·메시징
- **@google/genai** — Google Gemini AI(도면·영수증·마케팅·인사이트·예약 두뇌)
- REST API 40여 개 — 인증(kakao/naver), 결제(toss), 토스플레이스 연동·동기화, AI(도면/영수증/메뉴판/세무/지원/인사이트), 인쇄 브릿지, 푸시, 예약·AI예약, 마케팅 생성·발행, 공개 사이트

### 데이터 · 인프라
- **Firebase** — Firestore(DB), Auth, Cloud Messaging(FCM 푸시), `firestore.rules`로 매장 격리 보안
- **Render** 배포 — API 서버 + 프론트(SPA) 분리 호스팅
- **PWA** — 홈 화면 설치 프롬프트, 백그라운드 푸시
- **자체 경량 i18n** — localStorage 기반 4개 언어, 키 누락 시 한국어 폴백

### 아키텍처 특징
- **멀티테넌트** — storeId 기준 데이터·테마·권한 격리
- **역할·등급 라우트 가드** — 로그인/역할/출근/권한등급 4중 가드, 경로 정규화로 우회 차단
- **실시간** — 주문·테이블·결제 상태가 Firestore 구독으로 즉시 반영
- **오프라인 내성** — 연결 복구 시 자동 동기화
- **비정규화 스냅샷** — 영수증·주방표는 주문 시점 옵션명·가격을 보존(나중에 메뉴가 바뀌어도 과거 기록 불변)

## 8. 차별점 요약

- **통합** — POS·CRM·ERP·마케팅·예약이 한 앱. 데이터가 흩어지지 않음
- **AI 네이티브** — 도면·영수증·마케팅·인사이트·전화예약까지 AI가 실무를 대신
- **버튼 최소화** — 주문 2단계, 테이블 자동 전이로 운영 피로 ↓
- **다국적 매장 대응** — 4개 언어 + 직원 권한 등급으로 큰 매장도 커버
- **책임 있는 자동화** — AI 발행은 사람 승인 게이트·감사 로그·발행 한도

- AI 비서의 자율도 단계적 확대(가드레일 유지)
- 멀티 매장(체인) 운영 대시보드
