1. 결이란 무엇인가요?

결(Gyeol)은 식당 사장님이 손님 주문·결제·단골 관리를 한 번에 할 수 있는 무료 프로그램입니다.

💡 결로 할 수 있는 일

  • 손님이 QR 코드만 찍으면 메뉴를 보고 주문해요
  • 사장님 폰으로 새 주문이 왔다고 알림이 와요
  • 영수증이 자동으로 매장 프린터에서 출력돼요
  • 손님이 몇 번 왔는지, 뭘 좋아하는지 자동으로 기록돼요
  • 단골 손님에게 쿠폰을 줄 수 있어요
  • 매일·매주·매월 매출을 한눈에 볼 수 있어요

🆓 사용료

⚠️ 베타 기간 한정 지금은 베타 기간이라 사용료가 0원(무료)입니다.
정식 출시 후 사용료는 별도 안내 예정이며, 베타 매장은 충분한 사전 안내 후 전환됩니다.
  • 베타 기간 동안 완전 무료
  • 인터넷·핸드폰 데이터만 있으면 사용 가능

2. 시작하기 — 가입과 매장 설정

📱 처음 가입하기 (5분)

1
인터넷 주소 열기
핸드폰이나 PC의 인터넷에서 다음 주소를 입력해주세요:
https://gyeol-app.onrender.com
2
"사장님으로 시작" 버튼을 누릅니다.
3
가입 정보 입력:
칸입력할 것
매장 이름예: 결식당, 김밥천국 강남점
사장님 성함예: 홍길동
전화번호010-0000-0000
4
약관 동의 → 가입 완료
💡 알아두면 좋아요 한 번 들어가신 후 화면 우측 상단의 🔖 별표(즐겨찾기) 또는 핸드폰의 공유 → 홈 화면에 추가를 해두시면 다음부터 빠르게 접속할 수 있어요.

🏪 매장 기본 설정

가입이 끝나면 좌측 메뉴 브랜드 설정을 누르세요. 처음 한 번만 설정하면 돼요.

꼭 설정해야 하는 것

  1. 매장 이름 — 영수증·QR 인쇄에 사용됨
  2. 업종 — 한식·카페·고깃집 등
  3. 보상 방식 — 포인트 / 스탬프 / 등급제 중 하나
  4. 매장 위치 — "위치 가져오기" 버튼 누르면 자동 입력

나중에 해도 되는 것

  • POS 연동 (이지포스·OKPOS 등)
  • 알림톡·SMS 연동
  • 결제 시스템 연동

3. 메뉴 등록하기

메뉴 추가하는 법

1
좌측 메뉴에서 메뉴 관리 클릭
2
우측 상단 + 새 메뉴 버튼 클릭
3
메뉴 정보 입력:
칸입력 예시
이름김치찌개
가격8000 (숫자만)
분류식사류 (예: 식사·찌개·고기·음료·반찬)
설명(선택) "매콤하고 진한 국물"
4
저장 클릭 → 메뉴 목록에 즉시 추가됩니다.

메뉴 품절 표시

매장에서 "김치 떨어졌어요!" 같은 상황엔:

  • 메뉴 옆 토글 스위치 클릭 → 손님 화면에서 안 보임
  • 다시 클릭 → 다시 판매

메뉴 수정·삭제

메뉴 우측 연필 아이콘 → 수정 또는 휴지통 아이콘 → 삭제

4. 테이블 배치하기

손님이 어느 자리에 앉을지 정해주는 단계예요.

🚀 빠른 방법 — 도면 사진으로 자동 만들기 (AI)

1
좌측 메뉴 테이블 편집 클릭
2
도면 업로드 버튼
3
매장 도면 사진 선택 (또는 손으로 그린 스케치도 OK)
4
AI 초안 자동 생성 클릭
AI가 30초 안에 도면을 분석해 테이블을 자동 배치
5
결과 확인 → 적용 클릭
💡 알아두면 좋아요 AI가 잘못 인식한 자리는 마우스로 끌어서 옮기시면 돼요. 룸(별실)은 + 테이블 추가 → 룸 선택.

✋ 수동으로 만드는 법

  1. + 테이블 추가 버튼
  2. 화면에 새 테이블이 나타남 → 마우스로 끌어서 위치 조정
  3. 테이블 클릭 → 우측에서 인원수·모양(사각/원형) 변경
  4. 끝나면 자동으로 저장됨

5. QR 코드 인쇄 후 부착하기

인쇄하기

1
좌측 메뉴 QR 인쇄 클릭
2
템플릿 선택:
종류추천 상황
디럭스 ⭐처음 사용 — 사용 방법이 자동으로 같이 인쇄됨
미니멀잉크 절약
와이드테이블 번호를 크게 보여주고 싶을 때
3
종이 종류 선택:
  • A4 종이 → 잘라서 사용
  • 스티커 라벨 → 24칸짜리 라벨지
  • 명함 종이 → 10칸짜리
4
우측 상단 인쇄 버튼

테이블에 붙이기

  1. 인쇄한 종이를 가위로 자르기
  2. 각 테이블 번호 확인
  3. 손님이 바로 보이는 위치에 부착 (테이블 모서리, 양념통 옆 등)
  4. 투명 시트지나 코팅으로 덮으면 오래 사용 가능

6. 영수증 자동 인쇄 프로그램 설치

🤔 꼭 해야 하나요?

  • POS API가 연동된 매장 → 안 해도 됨 (POS에서 자동 인쇄)
  • POS 없거나 수동 매장 → ⭐ 꼭 설치 권장

설치 방법

1
결 웹앱 → 브랜드 설정 → 영수증 자동 인쇄
2
결 인쇄 브릿지 프로그램 다운로드 클릭
3
다운로드된 .exe 파일 더블클릭
4
Windows 보호 경고 발생 시:
"Windows에서 PC를 보호했습니다" 경고는 정상이에요.
→ 추가 정보 → 실행 클릭
5
설치 마법사 진행 (3분)
6
우측 하단 트레이에 🟢 결 아이콘 생김

페어링 (매장 연결)

1
결 웹앱 → 브랜드 설정 → 영수증 자동 인쇄
2
자동 인쇄 사용 토글 켜기
3
페어링 코드 발급 클릭 → 6자리 숫자 표시 (예: 483921)
4
PC 우측 하단 트레이 🟢 결 아이콘 우클릭 → 매장 연결
5
6자리 코드 입력 → 연결
6
"결식당 강남점과 페어링되었어요" 메시지 → 성공! 🎉

프린터 선택

1
같은 창에서 프린터 선택 드롭다운
2
사용할 영수증 프린터 선택 (EPSON, 빅솔론 등)
3
제조사 선택
4
테스트 인쇄 버튼 → 종이가 나오면 끝!
💡 알아두면 좋아요 이후 손님이 결제 승인하면 영수증이 자동으로 출력됩니다. 한 번 깔면 자동 업데이트되어 평생 사용 가능해요.

7. 폰으로 알림 받기 (푸시 알림)

매장 화면을 보지 않고도 사장님 폰에 알림이 와요.

📱 알림 받는 종류

  • 🔔 새 주문 도착
  • 💳 손님이 결제 요청
  • 🎟 손님이 쿠폰 사용 요청
  • 👤 새 직원 가입 요청

알림 설정 방법

1
결 웹앱 → 브랜드 설정 → 푸시 알림 섹션
2
이 기기로 알림 받기 버튼 클릭
3
브라우저 권한 팝업 → 허용
4
"이 기기 알림 켜짐 · 총 1대 등록" 메시지 → 성공!

여러 기기에서 알림 받기

사장님 폰뿐만 아니라 태블릿·매장 PC 어디서든 같은 방법으로 등록 가능. 어떤 기기에서든 결 웹앱 로그인 → 브랜드 설정 → "이 기기로 알림 받기"

⚠️ 주의:
  • iPhone: 결 웹앱 열고 → 공유 → 홈 화면에 추가 한 뒤에만 작동 (iOS 16.4 이상)
  • Android·Windows·Mac은 그냥 브라우저에서 바로 작동
  • 권한 거부 시: 주소창 왼쪽 🔒 자물쇠 → 알림 → 허용

8. 영업 시간 설정

영업 시간을 등록하면 영업 외 시간에 손님 주문이 자동으로 차단돼요.

설정 방법

1
결 웹앱 → 브랜드 설정 → 영업 시간 섹션
2
요일별로 영업 시간 입력. 예시: 
월요일 09:00 ~ 22:00
화요일 09:00 ~ 22:00
...
일요일 휴무
3
휴게 시간 (선택): 점심 후 잠시 닫는 식당이면 + 쉬는시간 클릭 → 시간 입력 (예: 15:00 ~ 17:00)
4
24시간 영업: 24시간 운영 매장은 토글 켜기 → 요일별 시간 무시
5
특정 날짜 휴무 (명절·임시휴무): 날짜 선택 → 추가 클릭
6
영업 시간 저장 버튼

긴급 임시 마감

갑자기 매장을 닫아야 할 때:

  • 매장 상단의 🟢 영업 중 칩 클릭 → 🔴 마감으로 즉시 변경
  • 사유 입력 (선택): "재료 소진", "사장님 부재" 등
  • 다시 클릭하면 영업 재개

→ 손님이 QR 찍어도 "지금은 주문할 수 없어요" 안내가 표시됩니다.

9. 주문 받기 — 손님이 QR 찍으면

흐름 한눈에

손님이 QR 찍기
    ↓
손님 회원가입·로그인
    ↓
메뉴 보고 카트 담기
    ↓
주문하기 버튼
    ↓
🔔 사장님 폰에 알림 도착!
    ↓
주문 화면에 새 주문 카드 표시

사장님이 할 일

1
좌측 메뉴 주문·쿠폰 클릭
2
새 주문 카드 (네이비 강조) 확인
3
접수 완료 버튼 1번 클릭 → 자동으로 "조리 중" 상태로 변경
4
조리 완료 후 서빙 완료 버튼 1번 클릭 → 끝!
💡 알아두면 좋아요 사장님이 누르는 버튼은 총 2번이에요.
다른 POS는 4단계인데, 결은 2단계로 단순화했어요.

주문 취소 / 영수증 재인쇄

  • 주문 카드의 취소 버튼 → 확인 → 취소됨
  • 주문 카드의 재인쇄 버튼 → 영수증 다시 출력

10. 결제 처리하기

새 결제 흐름

손님이 '결제하기' 누르기
    ↓
💳 사장님 폰 알림: "결제 요청 — 테이블 N · ₩50,000"
    ↓
사장님: 주문 페이지 → 노란색 "결제 요청" 카드
    ↓
사장님: '결제 승인 + 영수증 출력' 클릭
    ↓
📄 총 영수증 1장 자동 출력 (모든 주문 합산)
    ↓
사장님: 테이블 클릭 → '계산 완료 → 테이블 비우기'

사장님이 해야 할 일

방법 A. 주문 페이지에서

  1. 좌측 주문·쿠폰 클릭
  2. 상단 "💰 결제 요청" 카드 (노란색)
  3. 결제 승인 + 영수증 출력 클릭

방법 B. 대시보드 테이블 카드에서

  1. 대시보드 → 결제 요청 들어온 테이블 클릭
  2. 모달 상단의 결제 요청 배너 (노란색)
  3. 결제 승인 + 영수증 출력 클릭
  4. 사장님이 결제 받음 (현금·카드 단말기)
  5. 계산 완료 → 테이블 비우기 클릭

11. 테이블 관리 — 8단계 흐름

매장의 테이블은 8가지 상태로 자동으로 흘러가요.

8단계 그림

1. ⚪ 비어있음     ← 손님 없음
        ↓
2. 🟣 예약됨       ← 예약 등록하면 자동
        ↓
3. 🟡 세팅완료     ← 사장님이 "준비 완료" 클릭
        ↓
4. 🟢 손님입장     ← 손님이 QR 찍으면 자동
        ↓
5. 🟢 식사중       ← 첫 주문이 들어오면 자동
        ↓
6. 🔵 결제완료     ← 결제 승인하면 자동
        ↓
7. 🟠 정리중       ← "정리 시작" 클릭
        ↓
   다시 비어있음   ← "청소 완료" 클릭

사장님이 직접 누르는 단계

  • 세팅 완료 (③) — 손님 받을 준비
  • 정리 시작 (⑦) — 결제 후 정리
  • 청소 완료 (→①) — 다음 손님 받을 준비

나머지는 모두 자동으로 흘러갑니다.

테이블 상세 보기

대시보드에서 테이블 카드 클릭 → 모달 창이 열림

표시되는 정보

  • 현재 상태 (색깔 + 진행 바)
  • 체류 시간 (45분, 1시간 20분 등)
  • 인원수 / 손님 명단
  • 주문 목록 (각 주문의 메뉴·수량·금액·결제상태)
  • 합계 + 미결제 합계

12. 예약 받기

예약 등록

1
좌측 메뉴 예약 클릭
2
우측 상단 + 새 예약 버튼

17. 자주 묻는 질문 (FAQ)

Q1. 인터넷이 끊기면 어떻게 되나요?

A. 결은 인터넷이 다시 연결되면 자동으로 동기화돼요. 끊긴 동안 사장님이 입력한 데이터는 PC 안에 보관 → 연결되면 자동 전송.

Q2. 영수증 프린터를 안 샀어요.

A. POS 연동 또는 일반 A4 프린터로 인쇄 가능. 결제 승인 시 브라우저 팝업으로 출력됩니다.

Q3. 손님이 QR 찍었는데 회원가입을 안 해요.

A. 첫 가입은 1분 정도. 손님에게 "카카오로 5초 가입 가능해요"라고 안내해주세요.

Q4. 다른 매장 손님도 우리 매장 정보를 볼 수 있나요?

A. 아니에요. 손님은 QR 찍은 매장 정보만 볼 수 있어요. 매장 간 데이터는 완전히 분리됩니다.

Q5. 결을 그만 쓸 때 데이터는 어떻게 되나요?

A. 사장님 동의 후 삭제되며, 단골 손님 정보는 엑셀로 받아 가실 수 있어요.

Q6. 다른 매장 쿠폰이 우리 매장에서 쓰여요?

A. 아니에요. 쿠폰은 발급한 매장에서만 사용 가능해요.

Q7. 예약을 받았는데 손님이 안 와요.

A. 예약 카드의 노쇼 버튼 → 테이블이 자동으로 비어있음으로 복귀.

Q8. 인쇄 브릿지 프로그램이 자꾸 꺼져요.

A. 트레이의 결 아이콘 우클릭 → 자동 시작 체크 확인. 그래도 안 되면 재설치.

Q9. 사장님 폰을 새로 바꿨어요. 알림은?

A. 옛 폰: 알림 끄기. 새 폰: 결 웹앱 → 브랜드 설정 → 이 기기로 알림 받기.

Q10. 영업 시간 외 사장님 수동 주문 입력은?

A. 가능해요. 사장님은 영업 시간 무관하게 입력 가능. 손님 QR 주문만 차단됩니다.

18. 문제가 생겼을 때

⚡ 즉시 해결할 수 있는 것

"화면이 안 떠요" → 새로고침

  • PC: Ctrl + Shift + R
  • 핸드폰: 주소창 옆 새로고침 아이콘

"주문이 안 보여요" → 알림 권한 확인

  1. 브랜드 설정 → 푸시 알림
  2. 이 기기 알림이 켜져 있는지 확인
  3. 안 켜져 있으면 다시 등록

"프린터에서 영수증이 안 나와요"

  1. 프린터 전원 확인
  2. 종이가 들어가 있는지 확인
  3. PC 트레이의 결 아이콘이 🟢 (초록)인지 확인
  4. 🟡 노랑이면 인터넷 연결 확인
  5. 🔴 빨강이면 우클릭 → 다시 페어링

"푸시 알림이 안 와요"

  1. 결 웹앱 → 브랜드 설정 → 푸시 알림 → 상태 확인
  2. 권한 거부됐다면 → 주소창 왼쪽 🔒 → 알림 → 허용
  3. 종류별 토글이 켜져 있는지 확인

🆘 그래도 안 될 때

매장 담당 매니저에게 연락하실 때:
  1. 현재 화면을 사진 또는 캡쳐
  2. 언제 발생했는지 메모
  3. 무슨 작업을 하던 중이었는지 메모
위 3가지를 보내주시면 빠르게 해결해드려요.
