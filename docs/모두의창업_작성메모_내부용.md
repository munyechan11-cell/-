# 모두의창업 제출 — 내부 작성 메모 (제출 금지)

> 이 파일은 제출하지 않습니다. 제출본은 `docs/모두의창업_등록_초안.md` 하나입니다.
> 멘토 피드백 25개 항목(BEFORE/AFTER/이유)을 반영한 3판 기준으로 정리했습니다.

---

## 1. 제출 전 반드시 채워야 할 것

제출본에는 플레이스홀더를 남기지 않았습니다. 대신 아래는 **본인만 아는 사실**이라 문서에서 일반 표현으로 두었으니, 제출 전에 실제 내용으로 교체하거나 문단을 보강해야 합니다.

| 위치 | 현재 표현 | 해야 할 일 |
|---|---|---|
| 2장 풀버전 | "한 식당의 점심 피크 두 시간" | 매장 특성(업종·위치 성격)과 시점을 한 문장으로 보강. 상호는 밝히지 않아도 됨 |
| 4장 표 | "쌓이고 있는 데이터" 항목만 기재 | **파일럿 2곳의 실제 누적 수치**(운영 시작일, 누적 주문 건수, 등록 고객 수, 재방문 비율)를 넣으면 설득력이 크게 올라감. 멘토가 직접 요청한 항목 |
| 7장 2단계 | "한 상권을 정해" | 실제 진입 상권 이름을 명시할지 결정. 명시하면 실행 의지로 읽힘 |
| 10장 | 학력·전공·경력 문단 없음 | **반드시 사실 기반으로 추가.** 멘토 지적 25번. 없는 상태로 제출하면 감점 |
| 6장 | 자동화 플랜 월 2.9만 원 | 최종 가격 확정. 아래 3번 참고 |

## 2. 파일럿 실측치가 없을 때의 대응

4장 표의 수치를 아직 못 뽑는다면, 빈칸으로 두지 말고 "운영 N주차, 지표 수집 중"처럼 **수집 중인 상태를 사실대로** 적으십시오. 5장 지표표를 목표치 대신 "첫 달 실측값을 기준선으로 설정" 형태로 바꾼 것도 같은 이유입니다(멘토 지적 20번). 근거 없는 목표 숫자는 후속 질문에서 무너집니다.

## 3. 가격 구조 변경에 따른 코드 영향

멘토 지적 14번에 따라 요금을 **무료 코어 / 자동화 플랜(월 2.9만 원 내외) / AI 전화 기본료+통화량 구간제** 3단으로 바꿨습니다.

현재 코드는 채널 수 × 캠페인 수의 2축 게이트로 구현돼 있습니다(베타 기간 비활성). 제출 문안과 실제 구현이 어긋난 상태이므로, 유료 전환 전에 요금 게이트를 3단 구조로 정리해야 합니다. 심사에서 요금 질문이 나오면 "구조는 구현돼 있고 플랜 구성은 유료 베타 결과로 확정" 이라고 답하는 것이 안전합니다.

## 4. 앞부분에 쓰지 말 것 (질문 받을 때만 답변)

글꼴 선택, 4개 국어, 세무 절세 분석, 지원사업 추천, 업종별 기본 설정, 토스플레이스 매출 연동.

모두 구현돼 있지만 앞에 배치하면 "기능이 많은 넓은 서비스"로 읽힙니다(멘토 지적 11번). 질문이 나오면 "초기 타깃 매장에서 반복 수요가 확인되지 않아 우선순위를 뒤로 두었다"고 답하십시오.
